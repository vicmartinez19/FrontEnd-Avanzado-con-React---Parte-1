# Actividad 1: Base de DevfSeek con Vite, Tailwind y React Hook Form

## 📌 Descripción del Proyecto (Entrega Parte 1)
En esta primera entrega del Módulo 5 se establecen los cimientos de **DevfSeek** (un clon moderno de interfaz conversacional con IA):
- Configuración inicial con **Vite** y compatibilidad con **GitHub Pages** (`base: './'`).
- Estructuración de componentes modulares (`Header`, `MessageList`, `ChatInput`).
- Implementación de **React Hook Form** para control de entradas sin renders innecesarios.
- Integración de **Yup** con `@hookform/resolvers/yup` para validación estricta de prompts (longitud mínima, requeridos, sanitización).
- Renderizado interactivo de mensajes en tiempo real.
